# MCP-клиент учёта рабочего времени

Python-проект из трёх контейнеров:

- `mcp-server` — тестовый MCP-сервер со Streamable HTTP endpoint;
- `mcp-client` — CLI-клиент, использующий Ollama, Qwen и LangGraph.
- `mcp-client-http` — HTTP/SSE-шлюз и встроенный браузерный чат.

Рабочий MCP-сервер может находиться по HTTPS. Его URL и токен задаются через
переменные `MCP_URL` и `MCP_AUTH_TOKEN`.

## Инструменты MCP

Сервер предоставляет два инструмента:

- `get_employee_by_tab_number(tab_number: string)` — находит сотрудника по
  табельному номеру;
- `get_clock_event_id(employee_id: integer, date: string)` — возвращает время
  прихода и ухода за дату в формате `YYYY-MM-DD`.

Каждый инструмент возвращает единый результат:

```json
{
  "success": true,
  "data": {},
  "error": null,
  "message": "Операция выполнена"
}
```

Клиент построен как универсальный LangGraph-граф:

```text
agent → execute_tool → tool_result_router
                         ├─ success → agent
                         └─ error → tool_error → agent
```

При `success=false` новые инструменты для текущего вопроса отключаются, и агент
формирует пользователю ответ из `error` и `message`.

Тестовые данные включают сотрудника `tab-21` и событие за `2026-08-28` со
временем прихода `08:47:00`.

## Запуск

Нужны Docker Compose и локально запущенная Ollama. Перед первым запуском
загрузите модель:

```bash
ollama pull qwen2.5:7b-instruct-q4_K_M
```

Подготовьте настройки и соберите образы:

```bash
cp .env.example .env
docker compose build
```

Запустите тестовый MCP-сервер:

```bash
docker compose up -d mcp-server
```

Проверьте доступные инструменты без обращения к Ollama:

```bash
docker compose run --rm mcp-client --list-tools
```

Запустите интерактивный клиент:

```bash
docker compose run --rm mcp-client
```

Или запустите браузерный клиент:

```bash
docker compose up --build mcp-server mcp-client-http
```

После запуска откройте `http://localhost:8086`. Подробное описание SSE API и
пример подключения из Vue находятся в
[`mcp-client-http/readme.md`](mcp-client-http/readme.md).

После запуска задавайте вопросы в консоли:

```text
Вы> во сколько пришел на работу сотрудник с табельным номером tab-21 28 августа 2026
Ассистент> Сотрудник Иван Петров пришёл на работу в 08:47.

Вы> выход
```

История сохраняется до завершения процесса, поэтому можно задавать уточняющие
вопросы. Стрелки `↑` и `↓` переключают ранее введённые вопросы, а `←` и `→`
перемещают курсор внутри строки. Для выхода введите `exit`, `quit`, `выход` или
нажмите `Ctrl+D`.
Если отдельный запрос завершится ошибкой, клиент покажет её и продолжит принимать
вопросы; неудачный запрос в историю диалога не попадёт.

Клиент выводит в stderr логи подключения, шагов LLM и вызовов MCP. Детализация
задаётся переменной `LOG_LEVEL` (`INFO` по умолчанию, `DEBUG` для диагностики).

Для одиночного запроса используйте `--once`:

```bash
docker compose run --rm mcp-client --once \
  во сколько пришел на работу сотрудник с табельным номером tab-21 28 августа 2026
```

Ожидаемый ответ содержит время прихода `08:47`.

## Подключение рабочего MCP-сервера

Укажите в `.env` адрес и токен рабочего сервера:

```dotenv
MCP_URL=https://mcp.example.com/mcp
MCP_AUTH_TOKEN=replace-me
```

Остальная конфигурация клиента останется без изменений.
